# Ghostshift Playground

Public test project for [Ghostshift](https://github.com/rastislavelias/ghostshift).

AI changes are reviewed as patches before anyone applies them. The initial sandbox permits changes only to `app/page.tsx` and `app/globals.css`; dependencies, configuration and tests are fixed.

Node.js 24: `npm ci`, `npm test`, `npm run build`, `npm start`.

No client data or credentials belong here.
