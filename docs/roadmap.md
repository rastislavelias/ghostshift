# Roadmap

Implemented: brief capture, configurable local/API planning, persisted jobs and attempts,
plan versions, owner edits, feedback and approval, followed by one bounded Next.js playground
development task with LangGraph, isolated checks, patch review and human acceptance.
See [planning](workflow.md) and [development](development.md).

Next: apply an accepted patch to a dedicated branch and open a reviewable pull request,
with explicit authorization and conflict checks against its recorded base commit.
Then add visual preview/review and expand task types after strengthening execution isolation.

Client email, marketing, accounting, Figma automation, autonomous production deployment
and Kubernetes remain outside the current milestone.
